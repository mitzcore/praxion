⏱ Two different operating speeds

Muse / cloud: between bounded experiments or revision cycles (seconds or longer). Local control: fixed interval, such as 0.2–1 second; never wait for Muse to enforce safety.

🔒 Non-negotiable boundary

Raw Muse-generated code cannot command physical GPIO directly. Sandbox, approval, action limits, and hardware protections remain outside the model.

MVP 2 · Raspberry Pi (optional)

  • Same PlantAdapter: swap simulator for a physical level sensor and low-voltage pump without rewriting Muse's reasoning loop.
  • Physical proof: a reviewed, approved controller runs in short bounded tests and controls measured water level.
  • Fail safe: pump shuts off for emergency stop, sensor faults, and runtime failure; independent protection required.
  • Honest boundary: never call a simulated controller physically validated until real sensors and actuator have been tested.
